# 📖 Project Overview

The **Personal Portfolio Website** is a responsive web application designed to present my professional profile and development journey in a clean and interactive interface.

The portfolio provides visitors with an overview of my technical skills, education, internship experience, projects, and contact information.

The website focuses on a modern UI, responsive design, smooth animations, and easy navigation across different sections.

# 🚀 Installation
- Clone Repository
- Install Dependencies
- npm install
- Start Development Server
- npm run dev

The application will run using the Vite development server.

---

# 📦 Production Build

To create an optimized production build:

- npm run build

- The production files will be generated inside the dist/ directory.
